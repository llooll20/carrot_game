# 경제 순환 구조

```mermaid
flowchart TD

    %% 경제 주체
    P[플레이어]
    N[NPC]
    B[은행 / 금융]
    M[시장]

    %% 생산 영역
    R[자원]
    PR[생산 / 가공]
    S[재고]
    T[운송]
    G[상품 / 생산물]

    %% 플레이어 경제 순환
    P -->|자원 구매| M
    M -->|자원| P

    P -->|생산| PR
    R --> PR
    PR --> G
    G --> S
    S --> T
    T -->|판매| M
    M -->|판매대금| P

    %% 시장
    N -->|구매 / 판매| M
    M -->|가격 변화| N
    P -->|구매 / 판매| M
    M -->|가격 변화| P

    %% NPC 생산
    N -->|생산| PR
    PR -->|상품| N

    %% 금융
    P -->|대출 / 예금 / 보험| B
    B -->|자금 / 금융서비스| P
    N -->|대출 / 예금 / 보험| B
    B -->|자금 / 금융서비스| N

    %% 계약
    P <-->|계약| N
    P <-->|금융 계약| B

    %% 시장 가격
    M -->|수요 / 공급| M
